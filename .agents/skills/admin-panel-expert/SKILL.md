# Admin Panel Qurish Qoidalari (Top 10 GitHub Texnologiyalari)

Ushbu skill tizim monitoringi, foydalanuvchilarni boshqarish va kameralarni sozlash uchun Dashboard yaratishga yo'naltirilgan.

## Top 10 GitHub Vositalari & Qoidalar
1. **Refine (yoki React Admin)** - B2B admin panellar va CRUD ilovalarni juda tez qurish imkonini beruvchi freymvork.
2. **Tremor** - React uchun qisqa va chiroyli Dashboard/Analitika vizual komponentlari (grafiklar).
3. **TanStack Table** - Katta jadvallarni (DataGrid) sahifalash (pagination), filtrlash va tartiblash uchun boshsiz (headless) kuchli kutubxona.
4. **Recharts / Chart.js** - Ma'lumotlarni vizualizatsiya qilish (davomat, faollik foizlari).
5. **React Hook Form** - Katta va murakkab formalarni samarali, rendersiz boshqarish (Xodim qo'shish, bola kiritish).
6. **Zod Form Validation** - React Hook Form bilan birga ishlash va formalarni validatsiya qilish.
7. **Casbin (Node-Casbin)** - Murakkab RBAC (Role-Based Access Control) va ABAC huquqlarini tekshirish kutubxonasi.
8. **MUI (Material-UI) / Ant Design** - Agar Tailwind/Shadcn o'rniga korporativ standart UI kutubxonalari kerak bo'lsa.
9. **React Hot Toast / Sonner** - Qulay va tezkor bildirishnomalar (Notifications) oynalari.
10. **React-PDF / jspdf** - Admin panel orqali hisobotlarni PDF shaklida yuklab olish funksiyasi.

## AI Agentiga Ko'rsatma
Admin panelda xavfsizlik (JWT, Role checking) birinchi o'rinda turadi. Jadvallarda foydalanuvchilar (Ota-onalar, Tarbiyachilar) qulay filtrlash qidiruviga ega bo'lishi, shuningdek vizual analitika grafiklarga boy bo'lishi kerak.
