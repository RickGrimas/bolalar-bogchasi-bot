# Frontend Arxitektura Qoidalari (Top 10 GitHub Texnologiyalari)

Ushbu skill Telegram Mini App uchun **Frontend** qismini qotishlarsiz, "Native" darajasida silliq ishlovchi qilib qurishga yo'naltirilgan.

## Top 10 GitHub Vositalari & Qoidalar
1. **React.js** - UI komponentlarini qurish uchun asosiy kutubxona.
2. **Vite** - Loyihani yig'ish (build) va ishlab chiqish muhiti. Next.js dan ko'ra ancha yengil (SPA uchun).
3. **TypeScript** - Xatolarni kompilatsiya vaqtidayoq ushlash va Type-Safety ta'minlash.
4. **React Query (TanStack Query)** - Server holatini (Server State) boshqarish, keshlashtirish va ma'lumotlarni avtomatik yangilash.
5. **Zustand** - Global holatni (Client State) boshqarish uchun Redux'ga nisbatan yengilroq alternativa.
6. **React Router** - SPA ichida sahifalar o'rtasida navigatsiya qilish.
7. **Axios** - Backend API bilan ishlash, interceptor'lar orqali JWT tokenlarni avtomatik qo'shish.
8. **Vite PWA** - Ilovani oflayn ishlashi (Service Worker) va tez yuklanishi uchun PWA xususiyatlarini qo'shish.
9. **ESLint & Prettier** - Kodning sifatini va bir xil formatda bo'lishini ta'minlash.
10. **WebRTC API (Standard)** - MediaMTX dan kelayotgan video oqimni HTML5 `<video>` tegi orqali ko'rsatish (kuchli kutubxonalarsiz, sof WebRTC API yordamida).

## AI Agentiga Ko'rsatma
Frontend kodini yozayotganda Telegram Mini App talablarini hisobga oling (Telegram Web App scriptini ulash, `initData` ni o'qish, ekran o'lchamlariga 100% moslashish). Ortiqcha kutubxonalar ishlatmang, ilova yuklanish hajmi kichik (lightweight) bo'lsin.
