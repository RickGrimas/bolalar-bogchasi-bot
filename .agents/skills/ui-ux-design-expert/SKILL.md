# UI/UX Dizayn Qoidalari (Top 10 GitHub Texnologiyalari)

Ushbu skill foydalanuvchini (ota-onalar va adminlarni) hayratda qoldiradigan "Premium" dizayn va mikro-animatsiyalarni qo'llashga yo'naltirilgan.

## Top 10 GitHub Vositalari & Qoidalar
1. **Tailwind CSS** - Utility-first yondashuvi orqali tezkor va moslashuvchan dizayn yaratish.
2. **Shadcn UI** - O'zgartirish oson bo'lgan, ajoyib tarzda dizayn qilingan komponentlar to'plami.
3. **Radix UI (Primitives)** - Xavfsiz, qulay (Accessible - a11y) va boshqarish oson bo'lgan headless UI qismlari.
4. **Framer Motion** - React uchun eng mukammal mikro-animatsiyalar, sahifa almashish tranzaksiyalari (transitions) kutubxonasi.
5. **Lucide Icons** - Ochiq kodli, toza va chiroyli vektor ikonkalari to'plami.
6. **Tailwind Merge & clsx** - Dinamik Tailwind class'larini ziddiyatsiz birlashtirish (conditional classes).
7. **Headless UI** - Tailwind bilan mukammal ishlovchi, ko'rinishsiz UI logikalari.
8. **DaisyUI** - Tailwind uchun tayyor va chiroyli komponentlar plaginlari.
9. **Lottie Web** - Kichik hajmdagi, ajoyib vektor animatsiyalarni (Yuklanish, Xatoliklar) qo'shish.
10. **Storybook** - Barcha UI komponentlarini alohida, vizual muhitda sinash va dokumentatsiya qilish.

## AI Agentiga Ko'rsatma
UI kodini generatsiya qilganda qattiq ranglardan (sof qizil, yashil) qoching. HSL palitralar, oynasimon effektlar (Glassmorphism), qorong'u rejim (Dark Mode) va silliq interaksiyalardan (hover/active states) foydalaning. Ilova haqiqiy "Premium" ko'rinishga ega bo'lishi shart.
