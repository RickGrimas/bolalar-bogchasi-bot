# Backend va Ma'lumotlar Bazasi Qurish Qoidalari (Top 10 GitHub Texnologiyalari)

Ushbu skill loyihaning **Backend (API)** va **Database (Ma'lumotlar bazasi)** qismini noldan professional qurishda foydalaniladigan eng zo'r 10 ta ochiq kodli texnologiyalar va arxitektura qoidalarini o'z ichiga oladi.

## Top 10 GitHub Vositalari & Qoidalar
1. **Express.js / Fiber (Go) / FastAPI (Python)** - Asosiy API routing. Juda tez va yengil bo'lishi kerak.
2. **PostgreSQL** - Asosiy relyatsion ma'lumotlar bazasi. Barcha jadvallar (Foydalanuvchilar, Bolalar) qat'iy normallashtirilgan bo'lishi shart.
3. **Prisma ORM / GORM** - Ma'lumotlar bazasi bilan xavfsiz va tiplashtirilgan (Type-safe) ishlash uchun ORM.
4. **Redis** - Keshlashtirish va Rate limiting uchun (ayniqsa video strim ruxsatnomalari va JWT tekshiruvlarida).
5. **Docker / Docker Compose** - Butun backend infratuzilmasini (API, DB, Redis, MediaMTX) bitta konteyner ekotizimida izolyatsiya qilish.
6. **MediaMTX** - Kameralar WebRTC/RTSP oqimini past kechikish (low-latency) bilan uzatish uchun eng yaxshi server.
7. **Zod / Pydantic** - Kelayotgan barcha API so'rovlarni (Payload) qat'iy tipli validatsiyadan o'tkazish.
8. **Swagger (OpenAPI)** - API dokumentatsiyasini avtomatik generatsiya qilish. Frontend jamoasi (yoki AI) uchun muhim.
9. **Jest / Testify** - Backend logikasi uchun Unit va Integration testlar.
10. **Winston / Logrus** - Tizim xatolari va tranzaksiyalarni markazlashgan holda log qilish.

## AI Agentiga Ko'rsatma
Backend kodini yozishda faqat ushbu 10 ta texnologiyaga asoslaning. Monolit arxitektura o'rniga aniq modullarga (Controllers, Services, Repositories) ajratilgan toza kod (Clean Architecture) yozing.
