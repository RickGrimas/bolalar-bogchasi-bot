# Telegram Bot Qoidalari (Top 10 GitHub Texnologiyalari)

Ushbu skill Telegram Web App'ni ishga tushiradigan markaziy bot interfeysi, xabarnomalar va dinamik menyular yaratishni o'z ichiga oladi.

## Top 10 GitHub Vositalari & Qoidalar
1. **Telegraf.js (Node) / aiogram (Python)** - Asosiy bot logikasini, middleware va webhoooklarni yozish uchun kuchli freymvork.
2. **GrammY** - Telegraf muqobili, TypeScript'da yozilgan, juda moslashuvchan zamonaviy bot freymvorki.
3. **Telegram Web App API** - Mini App'lar bilan bot o'rtasidagi aloqa (`initData`, MainButton, BackButton).
4. **i18next (Telegraf i18n)** - Bot ichida ko'p tillilikni (O'zbek, Rus, Ingliz) ta'minlash.
5. **Redis Session (Telegraf/Aiogram)** - Bot sessiyalarini RAM'da ushlash orqali botni qotishlarsiz ishlashi va interaktiv suhbatlar (FSM) qurish.
6. **node-cron / APScheduler** - Vaqtga bog'liq avtomatik jarayonlar (Davomat yo'qlamasi, hafta yakunidagi bot-xabarlari).
7. **QR Code Generator** - Bolani topshirish xavfsizligi uchun vaqtinchalik (dynamic) QR kodlar yaratish.
8. **Winston (Bot Logging)** - Bot faoliyatidagi xatoliklarni qayd etish (ChatId topilmadi, block qilindi).
9. **BullMQ / Celery** - Katta miqdordagi push-xabarnomalarni (masalan, favqulodda e'lonlar) qotib qolmasdan galma-gal yuborish navbati.
10. **Telethon / Pyrogram** - Kengroq imkoniyatlar uchun (agar MTProto orqali mijoz API bilan ishlash kerak bo'lsa).

## AI Agentiga Ko'rsatma
Bot kodida ortiqcha menyular bo'lmasligi kerak. Asosiy maqsad - Web App (Mini App) ni ochish. Bot shunchaki xabarnoma qabul qiluvchi markaz vazifasini bajaradi. Sessiyalar asinxron va Redis'da saqlanishiga e'tibor bering.
